# Website Resmi SPS Raudlatul Ulum I Putra

Situs profil Satuan Pendidikan Salafiyah (SPS) Raudlatul Ulum I Putra,
Gondanglegi, Malang. Diterbitkan lewat GitHub Pages dari berkas `index.html`
tunggal — seluruh aset (logo, foto, gaya) sudah menyatu di dalamnya.

Alamat: https://sps-raudlatululum1.github.io/

Perubahan isi (berita, profil, pengurus) dilakukan lewat Muse atas perintah
pengelola; berkas ini bukan tempat mengisi berita secara langsung.
